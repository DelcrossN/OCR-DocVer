# OCR-DocVer
In today's fast-paced world, the need for efficient and accurate document verification processes is paramount across various sectors such as polling booths, airports, examination centers, and more. Traditional manual verification methods have long been associated with tedious, error-prone, and time-consuming processes. However, with the advent of Optical Character Recognition (OCR) technology, a new era of document verification has emerged.
Our project leverages OCR engine ‘Tesseract’ to extract text from image identity documents, enabling the digitalization of the verification process. By storing the extracted text information in a database, we streamline and enhance the efficiency of document verification procedures. This innovative approach not only ensures accuracy but also significantly reduces processing time compared to manual verification methods. Some benefits of this approach include but aren’t limited to-
    ‒	Speed and Efficiency: OCR technology allows for a significant reduction in processing time, enabling quick verification at polling booths, airports, examination centers, and other similar settings.
    ‒	Automation: By automating the extraction and storage of text information, our project minimizes human error and speeds up the verification process. 
    ‒	Real-time Access: Storing extracted text information in a database enables instant access to verified data, facilitating quick decision-making processes. This real-time access to information enhances the responsiveness of verification procedures, leading to improved operational outcomes.
    ‒	Scalability: It ensures that verification procedures can handle increased volumes of documents without compromising accuracy or efficiency.

Listed below are some of the Software dependencies this project entails, being-

1. ‘Anaconda Navigator’ to launch and run ‘Jupyter Lab’ on local-host.
2. ‘Python’ ver. 3.12.0+ as well as some essential python libraries such as-
    i.	cv2 (Open-cv):  for image manipulation.
    ii.	PyTesseract: for performing OCR in Jupyter with the help of Tesseract OCR Engine in the background.
    iii.	Pillow: for opening images.
    iv.	PyMongo: for database integration and establishing connectivity between Jupyter Lab and MongoDB.
    v.	re (Regex): Python has a built-in package called ‘re’, which can be used to work with Regular Expressions, utilized in indexing output strings.
    vi.	Matplotlib: for image visualization.
    vii.	NumPy: for facilitating advanced operations of the ‘cv2’ library.
3. ‘MongoDB’, specifically the ‘MongoDB Community Server’ and  MongoDB Compass’ application for establishing connectivity with a NoSQL Database management system, used for storing and managing records.
4. ‘Tesseract’ ver. 4.0+, which is an open source OCR platform that extracts text from images and documents without a text layer and outputs the document into a new searchable text file, PDF, or most other popular formats.
5. Text Editor
6. Media Viewer and Editor for image opening, manipulation, etc.
7. Data backup and recovery tools, etc.
